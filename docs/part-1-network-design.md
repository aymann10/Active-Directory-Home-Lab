# Part 1 — Network Topology Design

## 1. Objective
The objective of this stage was to create an initial network topology for my Active Directory home lab before implementing the environment.

## 2. Tools Used
- diagrams.net (draw.io) — for creating the network topology diagram.
- Oracle VirtualBox — planned virtualization platform for the lab.

## 3. Network Design
I created a preliminary diagram showing the planned infrastructure, including internet connectivity, network devices, servers, and client computers.

The diagram serves as a visual reference for planning the lab environment before configuring the virtual machines.

## 5. Project Scope
The overall project will explore an Active Directory environment and security monitoring using the tools covered in the MyDFIR tutorial series.

The exact roles of the systems and their network connections will be documented as they are confirmed and implemented during the following stages.

## 6. Learning Outcomes
- Practiced drawing a network topology.
- Learned the importance of planning infrastructure before implementation.
- Prepared an initial design for a virtual lab environment.
