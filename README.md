# Active-Directory-Home-Lab

## Project Overview
This project documents my hands-on learning journey building an Active Directory home lab using Oracle VirtualBox. The goal is to understand Windows domain environments, networking, and security monitoring through practical implementation.

## Objectives
- Understand Active Directory and Windows domain environments.
- Build and configure virtual machines in Oracle VirtualBox.
- Learn how Windows systems communicate in a lab network.
- Explore security event collection and monitoring using Splunk.
- Practice security testing and understand the telemetry generated by lab activities.

## Tools and Technologies
- Oracle VirtualBox
- Windows 10
- Windows Server
- Kali Linux
- Splunk
- Sysmon
- Atomic Red Team

*These tools are planned or used as the project progresses; their implementation status is documented in the relevant sections.*
